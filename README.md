# My resume webapp with react

CV / portafolio personal construido con [React 18](https://react.dev) y [Vite](https://vitejs.dev), publicado en GitHub Pages.

## Desarrollo

```bash
npm install
npm run dev
```

El sitio corre en `http://localhost:5173/resume/`. El contenido (educación, empleos, habilidades, portafolio) se edita en [public/resumeData.json](public/resumeData.json) sin tocar código.

## Build y deploy

```bash
npm run build    # genera dist/
npm run deploy   # publica dist/ en la rama gh-pages
```
